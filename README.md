# Personal Portfolio Website

## About the Project

This is a simple personal portfolio website created using HTML and basic CSS. The website is designed to showcase my personal information, technical skills, and projects in a clean and organized manner.

This project is a beginner-friendly web development project that helped me improve my understanding of HTML and CSS and gain practical experience in building websites.

## Features

- Simple and clean user interface
- Personal introduction and About Me section
- Skills and projects showcase
- Contact information section
- Easy navigation between sections
- Basic responsive design

## Technologies Used

- HTML5 – For creating the structure of the website.
- CSS3 – For styling, layout, colors, and fonts.
